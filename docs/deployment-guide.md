# OMR 答题卡阅卷 APP — 小白部署指南

> 适用人群：教师 / 非技术用户  
> 更新时间：2026-07-06  
> APP 版本：v1.0

---

## 一、快速获取 APK（3 种方法）

### 方法一：从 GitHub 下载（推荐，零门槛）

1. 打开手机/电脑浏览器，进入项目 Actions 页面：
   👉 **[https://github.com/hwanginfo/omr_scanner/actions](https://github.com/hwanginfo/omr_scanner/actions)**

2. 你会看到一个列表，点击最新的绿色 ✓（Build APK #xx）

3. 在打开的页面底部，找到「Artifacts」区域

4. 点击 **omr-scanner-debug-apk** 下载压缩包

5. 解压后得到一个 `.apk` 文件

### 方法二：扫码安装（最快）

> 需要等构建完成后，由开发者生成二维码。

### 方法三：找开发者要 APK

直接联系开发者，让 TA 通过微信/QQ 发给你 `.apk` 文件。

## 二、安装到手机

### Android 手机安装步骤

**第 1 步：将 APK 传到手机**

| 方式 | 操作 |
|------|------|
| 微信/QQ | 把 APK 文件发送到「文件传输助手」，在手机上打开 |
| AirDrop（苹果⇔安卓） | 不适用，用微信/QQ 代替 |
| 数据线 | 连接电脑和手机，把 APK 复制到手机「下载」文件夹 |
| 网盘 | 上传到百度网盘，手机上打开网盘下载 |

**第 2 步：开启「允许安装未知来源应用」**

不同手机位置不同，一般如下：

- **小米/红米**：设置 → 安全 → 未知来源安装 → 允许
- **华为**：设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 允许
- **OPPO/vivo**：设置 → 安全 → 未知来源安装
- **三星**：设置 → 生物识别和安全 → 安装未知应用
- **其他品牌**：设置里搜「未知来源」或「安装未知应用」

**第 3 步：点击安装**

找到 APK 文件 → 点击 → 点「继续安装」→ 等待几秒 → 点「完成」

### 安装后的图标

安装完成后，桌面会出现一个叫 **「OMR 答题卡阅卷」** 的图标，点击即可打开。

## 三、首次使用向导

打开 APP 后，按照以下步骤操作：

### 1️⃣ 授予权限

第一次打开会提示需要权限：

- **相机权限**（必须）→ 点「允许」— 用于扫描答题卡拍照
- **存储权限**（建议允许）— 用于保存导出文件

> 如果误点了「拒绝」，可以去手机「设置 → 应用管理 → OMR 答题卡阅卷 → 权限」中重新开启。

### 2️⃣ 创建答题卡模板

1. 底部切换到「**模板**」标签（📄 图标）

2. 在「内置模板」区域，选择你需要的模板：

   | 模板名称 | 适用场景 |
   |----------|---------|
   | 20题（单选） | 小测验、随堂练习 |
   | 30题（单选） | 单元测试 |
   | 50题（单选） | 期中/期末考试 |
   | 100题（单选） | 大型考试 |
   | 20题（判断） | 判断题练习 |
   | 50题（判断） | 判断题考试 |

3. 点击模板卡片上的「**添加**」按钮

4. 添加成功后，模板会出现在下方「我的模板」列表中

### 3️⃣ 生成答题卡 PDF 并打印

1. 在「我的模板」列表中，找到刚添加的模板
2. 点击右侧的 ⋮（更多）按钮
3. 选择「**导出 PDF 打印**」
4. 系统会生成 A5 横向答题卡 PDF，点击「打开」查看
5. **打印设置建议**：A4 纸打印（一面印一张），打印后沿中间裁开

### 4️⃣ 录入标准答案（两种方式）

**方式 A：扫描母版（推荐）**

1. 打印一张答题卡，学号区填涂 **0000**
2. APP 首页选择对应的模板
3. 点击「**扫描答题卡**」按钮
4. 拍照后自动识别，弹出「标准答案已录入」即成功

**方式 B：手动录入**

1. 在模板管理页，点击模板右侧 ⋮ → 「录入标准答案」
2. 选择「手动逐题录入」
3. 逐题选择正确答案

### 5️⃣ 开始阅卷

1. 打印答题卡发给学生填写
2. 学生填涂：学号区填涂 **4 位学号**，答题区填涂答案
3. 打开 APP → 首页 → 选择对应模板
4. 点击「**扫描答题卡**」→ 拍照
5. 系统自动识别、批改，弹出结果：
   - ✅ 绿色 = 做对了
   - ❌ 红色 = 做错了
   - 总分 = 正确数
6. 点击「继续扫描」扫描下一张

### 6️⃣ 查看成绩统计

1. 底部切换到「**统计**」标签（📊 图标）
2. 输入学号可筛选单个学生成绩
3. 查看：分数分布图、单题正确率、答卷明细
4. 点击右上角 📥 图标导出 Excel

### 7️⃣ 班级管理（可选）

1. 底部切换到「**班级**」标签（👥 图标）
2. 点击右上角 **+** 添加班级
3. 班级下可以：手动添加学生 / 导入 CSV 学生名单

## 四、常见问题 FAQ

### Q1：安装时提示「解析包出错」

**原因**：APK 文件下载不完整。  
**解决**：重新下载，确保下载完成后再安装。

### Q2：打开 APP 闪退

**原因**：手机系统版本过低。  
**解决**：本 APP 需要 **Android 7.0（API 24）及以上**。  
查看手机系统：设置 → 关于手机 → Android 版本。

### Q3：拍照后识别失败

**原因**：拍照角度不好或光线不足。  
**解决**：
- 尽量在光线充足的环境下拍照
- 答题卡放平整，手机正对答题卡拍照
- 确保答题卡四个角完整入镜

### Q4：学号识别不对

**原因**：学号填涂不清晰。  
**解决**：学号区域有 4 列数字（0-9），每列选一个数字用铅笔 **填满** 涂黑。

### Q5：没有相机权限

**解决**：去手机「设置 → 应用管理 → OMR 答题卡阅卷 → 权限」中开启相机权限。

### Q6：导出的 Excel 在哪里？

**解决**：导出成功后 APP 会提示文件路径。一般位于手机的「文档」或「Download」文件夹中。

### Q7：能否导出其他格式？

目前支持导出 **Excel (.xlsx)** 格式，可用 WPS/Office 直接打开。

### Q8：需要网络吗？

**不需要！** 本 APP **完全离线运行**，不需要任何网络连接。

### Q9：支持多人同时登录吗？

**不支持。** 本 APP 为教师单人单设备设计，数据仅存储在本地，不涉及网络传输。
